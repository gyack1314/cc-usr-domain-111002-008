# 区间采集 RPA（rpa/）

把业务组给的**带偏移绝对时间范围**（ISO 8601，起点包含、终点不包含）准确转换成
门户本地墙上时间查询，完成区间采集并留下边界证据。门户时区以页面显示为准，
浏览器本机时区可以不同。

## 转换规则（区间计划）

- 输入必须是**整分钟**的带偏移 ISO 时间；含秒或亚秒的输入在启动浏览器前拒绝
  （`InvalidRangeError`），不做舍入。空范围（终点不晚于起点）不发任何请求。
- 门户单次查询最多覆盖一个当地自然日，且**两个端点都包含**。因此按门户当地
  自然日切分子区间，每段的查询终点 = 区间终点（不含）− 1 分钟，按分钟离散点
  形成等价查询：`[start, end)` ⇔ 逐段查询 `[段起点, 段终点−1min]`。
- 重复时段（2026-11-01 的 01 点出现两次）用页面偏移选项区分：`0` 第一次
  （UTC−04）、`1` 第二次（UTC−05）；fold 由绝对时刻经 `zoneinfo` 解析，不从
  墙上时间猜测。不存在的当地时间（2026-03-08 02 点）不出现在任何段的端点中。

## 使用方式

```sh
python -m portal --port 8090 &   # 启动本地门户

# 1) 区间计划：只输出切分结果，不打开浏览器
python -m rpa --portal http://127.0.0.1:8090 \
    --start 2026-11-01T00:30:00-04:00 --end 2026-11-01T01:30:00-05:00 --plan-only

# 2) 浏览器填写 + 3) 结果核对：真实点击日期控件，逐段核对并留证据
python -m rpa --portal http://127.0.0.1:8090 \
    --start 2026-11-01T00:30:00-04:00 --end 2026-11-01T01:30:00-05:00 \
    --browser-timezone Asia/Shanghai --evidence-dir evidence/run1 --screenshots
```

退出码：`0` 成功或空范围，`1` 采集中出现差异，`2` 输入被拒绝。

浏览器填写路径与人工一致：打开日历对话框 → 月份导航（上月/下月）→ 点击日期格
→ 选择时间选项 → 选择偏移选项。每一步都**读回控件实际值**比对意图；提交后先
核对 `#utc-summary` 与结果区的 `data-signature` 绑定，并确认页面自己的
`/api/action` 请求完成（网络层观察，不调用页面内部函数、不借用运维入口），
再读取绑定该摘要的结果记录。

遇到以下情况**停止该段并记录差异**，不凭输入值判断已经成功：

- 控件自动纠正（读回值与意图不符）或选项不可选；
- 切月后定位到错误日期（日期框读回不符）；
- 门户报错（如“当地时间不存在”）或限时内未确认（旧结果仍显示）。

## 汇总与证据

汇总按（绝对分钟, 来源编号）去重，每条命中保留来自哪个子区间
（`segments` 字段）；并按绝对分钟穷举对照整个区间，缺口与多出都如实列出，
不以去重掩盖。任一段有差异则整体状态为 `failed`，缺口分钟在报告中可见。

证据目录内容：

- `plan.json`：输入、门户时区、浏览器时区、每段意图（日期/时间/偏移/预期
  UTC 摘要）与执行证据（读回值、月份导航路径、页面状态、摘要、记录数、
  首末记录）；
- `records.jsonl`：去重后的命中，含 `id`、`utc`、`minute`、`segments`；
- `summary.json`：状态、命中数、去重数、缺口/多出计数与样例、差异详情；
- `segment-<i>.png`（可选）：每段提交后的整页截图。

## 场景证明（自动检查）

`tests/test_rpa_browser.py` 用真实浏览器点击完成三个场景，并对短区间**穷举
绝对分钟**做对照（`exhaustive_ids`），不调用日期转换函数代替浏览器联调：

1. **回拨日**：`2026-11-01` 重复 01 点的第一次/第二次偏移选择（含跨前一日
   23 点的范围），核对 fold 读回标签、UTC 摘要与逐分钟结果；
2. **跨当地午夜**：`2026-03-07 23:30 −05:00` → `2026-03-09 00:30 −04:00`，
   三段（30 + 1380 + 30 分钟，春拨日只有 23 小时），日历从 11 月真实导航
   8 次到 3 月，没有任何一段请求不存在的 02 点；
3. **浏览器时区不同**：浏览器设为 `Asia/Shanghai`，门户仍为纽约时区，选中
   的日期/偏移与结果与对照完全一致。

另覆盖：空范围不发请求、非整分钟在开始
前拒绝、不存在的时间停止该段并记录差异、未确认的查询（旧结果仍显示）不冒充
成功。运行：

```sh
python -m unittest discover -s tests -v
```
